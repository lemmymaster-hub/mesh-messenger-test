# BSL Mesh Lite

BSL Mesh Lite is an offline communication platform built with Flutter that enables messaging between mobile devices without internet access.

The system is designed for emergency response teams, search and rescue operations, disaster situations, outdoor events, humanitarian missions, and remote environments where traditional communication infrastructure is unavailable.

---

## Key Features

### Device Discovery

* Automatic Device Detection
* Nearby Connections Integration

### Mesh Communication

* Multi-Hop Relay Messaging
* Device-to-Device Communication
* Message Forwarding

### Messaging

* Broadcast Messages
* Private Messages
* Relay-Based Delivery

### Emergency Features

* SOS Alerts
* GPS Coordinates Sharing
* Emergency Response Workflow

### Offline Operations

* No Internet Required
* Local Data Storage
* Offline Sector Management

---

## Example Network

Phone A → Phone B → Phone C

If Phone C is outside the direct range of Phone A, messages can still be delivered through Phone B using relay routing.
